# CrashSensor uCut 微中断容限测试模块

作者: mozial

---

## 1. 模块定位与核心功能

本模块为汽车级碰撞传感器芯片（Crash Sensor）的微中断（uCut, Micro-Cut）容限自动化测试与特性分析套件。

在车载供电网络中，启动冲击、继电器抖动或电源瞬间跌落会导致供电线路上产生微秒（us）至毫秒（ms）级的跌落脉冲。本模块用于自动化注入 24 组不同跌落深度（Drop Voltage）与跌落持续时间（Duration）的电压波形，评估并量化芯片在各种极值故障下的工作边界、复位行为及掉电恢复后寄存器保持状态，并自动生成 Shmoo Plot 容限分布图。

## 4. 核心功能实现技术要点

### 4.1 易失 ARB 4秒热覆写无缝注入 (dg5072_ucut.py)
- 杜绝传统机械继电器切换引入的毫秒级抖动和电感反冲电压。
- 采用 Rigol DG5072 的 `VOLATILE` 内部 RAM 直接下载 16-bit 定制采样点，精确合成包含基准供电（V_BASE）、同步头高电平脉冲（V_SYNC_HIGH）及微中断低电平（V_CUT_LOW）的复合测试时序。
- 具备硬件安全保护：上电时严格遵守 DG5072 先就绪、再开启通道输出的安全时序，防止尖峰冲击击穿被测芯片。

### 4.2 串口/I2C 保持性校验 (pyserial_ucut.py)
- 掉电前通过串口写入修调寄存器（Trim Configuration）。
- 掉电微中断发生后，再次读取寄存器状态并进行比对，验证片上非易失存储器与上电复位（POR）电路的完整性。

### 4.3 示波器波形判定与特征提取 (sds5054_ucut.py)
- 配置 CH1 监测电源输入引脚，CH2 监测 10.03 欧姆采样电阻上的 PSI5 调制电流。
- 具备自动波形边沿识别、掉电时间宽度测量、掉电深度反向折算与恢复响应时延（Recovery Time）计算。

### 4.4 24 工况 Shmoo Plot 矩阵渲染 (ucut_control.py)
- 遍历 24 组工况（电压跌落范围覆盖 0V ~ 11V，脉宽覆盖 10us ~ 5000us）。
- 自动化输出带有红（FAIL）、绿（PASS）、灰色（MARGINAL）视觉标记的专业 Excel 容限分布图。

## 5. 快速启动与操作指引

### 5.1 环境准备
激活专用 Conda 虚拟环境：
```powershell
conda activate D:\project_momo\project_venv\venv_crashsensor
```

### 5.2 运行全自动测试
```powershell
cd D:\project_momo\auto-chip-validation-framework\crash_sensor\ucut_micro_cut
python ucut_control.py
```

### 5.3 运行控制说明
在控制台交互提示中：
- 输入 `a` 并按回车：开始顺序自动测试全部 24 组用例。
- 输入单个编号（例如 `5`）：单独测试第 5 组工况。
- 测试完成后，报表将自动保存于当前目录下的 Excel 文件中，内含 `Shmoo_Plot` 工作表。
